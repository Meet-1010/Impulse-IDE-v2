# Third-party notices

Impulse IDE 2.0.0-beta.2 includes the open-source packages below. Generated by `npm run notices`.

## Downloaded or provided at runtime

### arduino-cli 1.5.1 (GPL-3.0)

https://github.com/arduino/arduino-cli

Not bundled. When no arduino-cli is installed, Impulse downloads the official release into its data folder on request and runs it as a separate program; its LICENSE.txt is kept next to it. Board cores and libraries it installs carry their own licenses.

### Arduino-Pico core (rp2040:rp2040) latest (LGPL-2.1)

https://github.com/earlephilhower/arduino-pico

Not bundled. Installed through arduino-cli when you simulate a Raspberry Pi Pico for the first time and agree to the download; it brings its own toolchains and licenses.

### ATTinyCore (ATTinyCore:avr) latest (LGPL-2.1)

https://github.com/SpenceKonde/ATTinyCore

Not bundled. Installed through arduino-cli when you simulate an ATtiny85 for the first time and agree to the download; it uses the AVR compiler of the Arduino AVR core.

### ESP32 cores (esp32:esp32, arduino:esp32) installed (LGPL-2.1 and others)

https://github.com/espressif/arduino-esp32

Not bundled. Installed through arduino-cli when you simulate an ESP32 board without its core and agree to the download. Impulse compiles a small simulator bridge (src/main/services/esp32sim/impulse_sim.cpp) into sketches it simulates, never into uploads.

### Espressif QEMU esp-develop-9.2.2-20260417 (GPL-2.0-or-later)

https://github.com/espressif/qemu

The ESP32 emulator, run as a separate program. On Windows and Linux it is downloaded from Espressif's release the first time you simulate an ESP32 board (you are asked first) and checked against its published SHA-256. On macOS it ships with the app (Contents/Resources/qemu) together with the libraries listed next. Source code: https://github.com/espressif/qemu/releases/download/esp-develop-9.2.2-20260417/qemu-esp_develop_9.2.2_20260417-src.tar.xz. The ESP32 ROM images in its share/qemu folder are Espressif's.

### pixman 0.46.4 (MIT)

https://www.cairographics.org/releases/pixman-0.46.4.tar.gz

macOS only: built from the release source by scripts/qemu-mac-pack.mjs and shipped as a dynamic library next to QEMU.

### libgcrypt 1.12.4 (LGPL-2.1-or-later)

https://gnupg.org/ftp/gcrypt/libgcrypt/libgcrypt-1.12.4.tar.bz2

macOS only: built unmodified from the release source by scripts/qemu-mac-pack.mjs and shipped as a separate dynamic library (Contents/Resources/qemu/*/qemu/lib) that QEMU loads; it can be replaced with another build.

### libgpg-error 1.61 (LGPL-2.1-or-later)

https://gnupg.org/ftp/gcrypt/libgpg-error/libgpg-error-1.61.tar.bz2

macOS only: built unmodified from the release source by scripts/qemu-mac-pack.mjs and shipped as a separate dynamic library next to libgcrypt; it can be replaced with another build.

### Electron 44.5.1 (MIT)

https://www.electronjs.org

The app runtime. The licenses of Chromium and its components ship inside the app as LICENSES.chromium.html.

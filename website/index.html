01 / 05 · Ask

Say it in plain words.

Type what the project should do. The agent reads your sketch and circuit, makes a plan, and the orb shows each step as it works: reading, writing, compiling, testing.

  • Impulse AI through your account: free credits to start, no API key to bring
  • The agent can't run shell commands

02 / 05 · Write

It writes the sketch, then compiles it.

The code lands in the editor, not in a chat bubble. It compiles with arduino-cli for the board you picked, and compiler errors go straight back to the agent to fix.

  • Arduino-aware editor that flags pin mistakes as you type
  • Real arduino-cli, real libraries, multi-file sketches
  • PlatformIO projects open as they are

03 / 05 · Wire

It wires the circuit.

The circuit builder places the parts your sketch uses and wires them to the right pins. A circuit check catches missing resistors, floating inputs, shorts and I²C address clashes.

  • 91 parts: displays, NeoPixels, servos, steppers, sensors
  • Imports and exports Wokwi diagram.json
  • Hover a pin in the code to see what it's wired to

04 / 05 · Simulate

It runs before you touch hardware.

The compiled firmware runs on an emulated board. Write what should happen as comments, and every change the AI makes is tested, with a pass or fail card and a Fix with AI button. 

// @run 3s
// @expect serial contains "ready"
// @expect pin 13 frequency 1Hz ±10%
  • Logic analyzer and a debugger with breakpoints
  • The same tests run in CI with impulse-test

05 / 05 · Ship

Then it goes on your board.

Uploads go over USB once you approve them; the agent never flashes hardware on its own. The serial monitor picks up where the simulator left off, and you can diff the two line by line.

  • Any board arduino-cli supports, plus Upload Using Programmer
  • Simulator vs board: the same sketch, both serial logs compared
  • Export the compiled binary or archive the sketch

A simulator that runs your real firmware

Any board built on the ATmega328P, ATmega2560, ATtiny85 or RP2040 families, with parts that behave like the real ones: capacitors charge, servos sweep, displays draw. Real libraries work unchanged.

Tests written as comments

Describe what should happen. Impulse checks it in the simulator, and impulse-test does the same in CI.

// @expect serial contains "ready"
// @expect pin 13 toggles
// @expect pin 13 frequency 1Hz ±10%

✓ pin 13 toggles

Pin-aware editor

Boards

Simulate the chip. Upload to any board.

The simulator emulates the chip itself, so timers, interrupts and libraries behave as they do on the bench, on every board built around these chips: Uno, Nano, Pro Mini, Mega, Pico, XIAO RP2040 and more. Plug a board in and Impulse selects it; uploads go through arduino-cli, to any board it knows.

  • ATmega328P / 168

    Uno, Nano, Pro Mini, Fio, LilyPad, Duemilanove

  • ATmega2560 / 1280

    Mega 2560, Mega 1280, Mega ADK · 4 serial ports

  • RP2040

    Pico, XIAO RP2040, Feather RP2040 and about 100 more · 3.3 V

  • ATtiny25 / 45 / 85

    8 pins · software Serial · I²C and SPI over USI

  • Every other board

    ESP32, Uno R4, Leonardo, SAMD… compile, upload and Serial; not simulated yet
